# Demo video

## Keep these files
- **[`pps-demo-captions.mp4`](./pps-demo-captions.mp4)** — ~1:53 with on-screen labels (good default upload)
- **[`pps-demo-silent.webm`](./pps-demo-silent.webm)** — same take, no audio (best base for *your* voice)
- **[`VOICEOVER_TRANSCRIPT.md`](./VOICEOVER_TRANSCRIPT.md)** — what to say + timestamps
- **[`captions.srt`](./captions.srt)** — optional subtitle file

## How to voice it
1. Open the transcript  
2. Play the video  
3. Speak at each time marker  
4. Prefer recording over the **silent** file in CapCut, then upload to YouTube/Vimeo  

Rules: under **3 minutes** (1:53 is fine). Prefer **your voice** over AI TTS for the official entry.
